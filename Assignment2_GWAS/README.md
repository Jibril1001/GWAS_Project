# Assignment 2: GWAS Association Analysis

## Overview

This assignment applies a genome-wide association study (GWAS) to a simulated binary phenotype using genotype data from the 1000 Genomes East Asian (EAS) sample dataset.

The analysis follows the GWAS workflow from quality-controlled genotype data through association testing and visualization.

## Dataset

The genotype dataset contains 504 individuals from the East Asian populations of the 1000 Genomes Project.

The simulated binary phenotype is:

* Phenotype: `B1`
* Cases: 248
* Controls: 250

The association analysis was performed using PLINK 2.

## Association Analysis

The GWAS model used Firth logistic regression because the phenotype is binary.

The analysis included:

* Genotype data from the quality-controlled dataset
* Binary phenotype `B1`
* Minor allele frequency threshold of 0.01
* Five PCA-derived covariates to account for population structure
* Firth logistic regression

The five PCA covariates were taken from the projected PCA score file:

`plink_results_projected.sscore`

The PLINK command used for the analysis is available in:

`scripts/run_association_test.sh`

## Variants Tested

The initial dataset contained 1,224,104 variants.

After applying the MAF >= 0.01 threshold:

* Variants removed: 95,372
* Variants tested: 1,128,732

Firth regression was successfully completed for the analyzed variants.

## GWAS Results

The strongest association was observed at:

* Chromosome: 2
* Position: 55,587,876
* Variant: `chr2:55587876:T:C`
* P-value: `9.83091e-16`

Using the conventional genome-wide significance threshold of:

`P <= 5e-8`

the analysis identified:

**60 genome-wide significant variants.**

Several strong association signals were visible in the Manhattan plot, including a prominent cluster on chromosome 2 around 55.5-55.6 Mb.

Additional strong signals were observed on chromosomes 20, 1, and 7.

## Manhattan and Q-Q Plot

The Manhattan plot displays the strength of association across the genome.

* X-axis: genomic position across chromosomes
* Y-axis: `-log10(P)`
* Horizontal significance threshold: approximately `-log10(5e-8) = 7.3`

Most variants fall below the genome-wide significance threshold, while several regions contain strong association signals.

The Q-Q plot compares the observed distribution of P-values with the expected distribution under the null hypothesis.

The genomic inflation factor was:

**λGC = 0.9884**

This value is close to 1, indicating that the overall test statistics are well calibrated. The deviation in the extreme tail is consistent with the presence of strong association signals.

The Manhattan and Q-Q plots were generated using GWASLab.

## Interpretation

The GWAS identified multiple variants reaching genome-wide significance for the simulated `B1` phenotype.

The strong signal on chromosome 2 represents the most significant association in this analysis.

Because the phenotype is simulated, these associations should be interpreted as results of the analysis rather than evidence for a real human disease association.

The inclusion of PCA-derived covariates helps account for population structure, which is important because systematic ancestry differences can otherwise create confounding in GWAS.

* Variant and gene annotation

For this project, annotation and linkage-disequilibrium score regression (LDSC) were reviewed conceptually but were not run locally because the required external software and datasets were not available in the current environment.

Therefore, no LDSC or annotation results are presented as if they were generated by this analysis.

## Limitations

Several limitations should be considered:

1. The phenotype `B1` is simulated.
2. The dataset contains only 504 individuals, which limits statistical power.
3. The analysis uses a specific East Asian subset rather than a globally diverse population.
4. Genome-wide significant variants are statistical associations and do not by themselves establish causality.
5. Post-GWAS functional annotation was not performed locally.

## Conclusion

The GWAS workflow successfully identified statistically significant associations with the simulated `B1` phenotype.

The analysis tested more than one million variants while accounting for population structure using PCA-derived covariates. The strongest signal occurred on chromosome 2, with 60 variants reaching the conventional genome-wide significance threshold.

The Q-Q plot showed good overall calibration with λGC = 0.9884, while the Manhattan plot revealed several strong association regions.

This analysis demonstrates the main stages of GWAS association testing, visualization, interpretation, and the transition toward post-GWAS functional analysis.
